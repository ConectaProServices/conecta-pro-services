# 01-11 - Checklist de Validação

- [ ] Issue principal corretamente documentada.
- [ ] Caso de uso e escopo claramente definidos.
- [ ] Pelo menos 5 Sub-Issues com justificativa técnica e objetivo específico.
- [ ] Critérios de aceite claros, objetivos e verificáveis.
- [ ] Dependências mapeadas sem bloqueios circulares.
- [ ] Labels criadas e atribuídas consistentemente.
- [ ] GitHub Project configurado com os 5 estados da metodologia.
- [ ] Estado inicial das Issues condizente com a fase de planejamento.
- [ ] Rastreabilidade garantida entre requisito e atividade.
- [ ] Ausência de tarefas redundantes ou inventadas.
- [ ] Documentação de referência vinculada ao épico e às Sub-Issues.
- [ ] Responsáveis definidos para cada atividade ou marcados como `A definir`.
- [ ] Checklist de implementação futura visível para a equipe.
