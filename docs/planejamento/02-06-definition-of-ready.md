# 02-06 - Aplicação da Definition of Ready (DoR)

## 1. Critérios da DoR

- DoR-01: Objetivo claramente definido.
- DoR-02: Escopo delimitado.
- DoR-03: Critérios de aceite verificáveis.
- DoR-04: Dependências identificadas.
- DoR-05: Informações disponíveis.
- DoR-06: Responsável definido.
- DoR-07: Revisão concluída.

## 3. Regra de prontidão

Uma Issue deve ser movida para `Ready` somente quando a equipe confirmar, por revisão humana formal, que todos os critérios da DoR foram atendidos cumulativamente.

## 4. Conclusão

O conjunto de Issues está tecnicamente bem definido e dimensionado, porém ainda depende da formalização da revisão humana no GitHub para que a promoção para `Ready` seja aceita como regra de governança.
